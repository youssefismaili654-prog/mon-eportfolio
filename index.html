Preparatory Classes — 2026

Atmospheric Cycle: Modeling the Atmosphere as a Heat Engine

Scientific research project carried out during my preparatory classes at LYDEX, in collaboration with Ayman Quajih.

The project investigates atmospheric circulation through thermodynamic models, in order to estimate the physical limits of wind energy.

We compared an ideal Carnot model with a more realistic Curzon-Ahlborn model, taking thermal irreversibilities into account.

An experimental convective chimney was also designed to study the relationship between temperature differences and air velocity.

Thermodynamics Physics Experimental Analysis
ENSEEIHT — 1st Year — 3EA

Snake Game — C Programming Project

Design and development of a Snake arcade game in C as part of an engineering project at ENSEEIHT.

The objective is to create a playable game in which the player controls a snake using keyboard arrows, collects randomly generated apples and increases their score.

The project involves modular programming, data structures, game logic and algorithm design.

Main features include game options, stadium display, snake movement, apple generation, collision detection and score management.
